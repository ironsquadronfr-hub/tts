# Frozen — these files are served, not maintained

Everything in this directory is live: saves and mod versions out in the world
point at these exact URLs, and Tabletop Simulator caches by URL. So nothing
here is ever deleted, renamed or edited. It stays as it is, indefinitely.

**New assets do not go here.** They go to the store, which is a repository of
its own rather than a feature branch doing double duty as a CDN:

    https://github.com/ironsquadronfr-hub/swl-assets

Every file below has a copy there under the same name, and the mod's own code
now points at that copy. This directory remains only so that anything already
referencing it keeps working.
